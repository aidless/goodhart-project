# Q1 分析: 代理失真强度 vs 脱钩程度的曲线形状 [exploratory]

数据源: `c2/results/table1_true_score.csv`（`analyze_c2.py` 输出, n=5 seeds/档,
summary.csv sha256 记录于 `prereg/preregistration_c2.md` §4 补记）。
状态: **[exploratory]** —— 预注册只覆盖 C.2 判读 (§3), 本节是对同一数据的
探索性解读, 不构成新的确认性结论。数字全部来自上述 CSV, 未手抄自其他来源。

## 1. 观察到的曲线形状

| α | 0.5 | 1.0 | 1.5 | 2.0 | 2.5 | 3.0 |
|---|---|---|---|---|---|---|
| true_score | 444.0 | −2.2 | 39.4 | 59.4 | 21.3 | 11.3 |
| proxy_score | 0.643 | 1.376 | 1.067 | 0.855 | 1.064 | 0.811 |

- **true_score(α) 非单调**, 三段结构: 陡峭坍塌（α 0.5→1.0, −446.2 分）→
  局部回升（1.0→2.0, +61.7 分）→ 再衰减（2.0→3.0, −48.1 分）。
  峰值档 (α=0.5) 之后没有任何一档超过峰值的 13.4%。
- **proxy_score(α) 同样非单调**: 峰在 α=1.0, 峰后回落, α=2.5 处有一个
  次峰 (1.064) 后再降。
- Goodhart 交叉点 **α\* = 1.0**: proxy 全程最大 (1.376) ∧ true 全程最小
  (−2.2)。代理达成度与真实目标的一致性在此点完全翻转。

## 2. [exploratory] 机制假说（本批数据不能区分, 未检验）

训练奖励是**每步** speed^α（预注册 §0.2 记录的已知偏离; 报告量按预注册
定义为 mean(speed)^α）。按 α 的凸性分三段解释：

- **α < 1（亚线性, 只测了 0.5）**: 速度的边际收益递减 → 拉高速度不如
  保存活 → 存活主导 → true 高。
- **α = 1（线性）**: 每步速度线性累积, 存活不产生任何独立回报 → 最优解
  退化为"持续冲速", 碰撞终止不再构成机会成本 → true 崩至负值。
- **α > 1（超线性）**: 极端速度的回报被放大, 但 CartPole 动力学下高速
  加速失稳; α=2.0 的局部回升可能是超线性奖励把"中速折衷"策略变成了
  更可达的局部最优。2.5 后再衰减提示权衡再次倒向冲速。

附带观察：两个曲线的非单调性都说明 **H1 的"单调"字面在两个量上都不成立**；
"失真强度 → 真实损失"不是单调 dose-response, 而是至少存在两个机制切换点。
